# Web Análise App — Demo

Demonstração técnica de implementações realizadas durante o desenvolvimento de uma aplicação mobile Flutter voltada ao setor de agronegócio.

Este repositório foi criado com o objetivo de apresentar, de forma isolada e organizada, alguns dos principais conceitos e práticas utilizados no desenvolvimento da aplicação.

> **Nota:** Este repositório não contém o código-fonte completo da aplicação original. As implementações disponibilizadas aqui são demonstrativas e foram selecionadas para apresentação técnica, sem exposição de informações confidenciais. Além disso, diversos arquivos estão faltando, mesmo nas pastas existentes, especialmente quando se trata da pasta "Shared".


## 🎯 Objetivo

Apresentar na prática conhecimentos relacionados ao desenvolvimento de aplicações Flutter, principalmente em:

- Clean Architecture
- Consumo de APIs REST
- Tratamento de erros
- Gerenciamento de estado
- Injeção de dependências com Flutter Modular
- Implementação de funcionalidades envolvendo captura de imagens no dispositivo
- Separação de responsabilidades
- Desenvolvimento de interfaces reutilizáveis
- Organização e escalabilidade de código
